# Design + contrast (disease vs control), corrected labels from 4b
designMatrix   <- model.matrix(~ 0 + group, data = data.frame(group = pb_group))
contrastMatrix <- makeContrasts(groupdisease - groupcontrol, levels = designMatrix)

# Fit model
dge_disp <- estimateDisp(dge, designMatrix, robust = TRUE)
fit <- glmQLFit(dge_disp, designMatrix, robust = TRUE)

# Test
res <- glmQLFTest(fit, contrast = contrastMatrix)
res <- topTags(res, n = Inf)
sigRes <- subset(res$table, FDR < 0.05 & abs(logFC) > 1)

Working with single-cell RNA-sequencing data strengthened my understanding of essential analytical steps, including quality control, normalization, dimensionality reduction, clustering, and differential expression analysis.These skills are directly relevant to my PhD project, where I work with large immunological datasets generated from vaccine studies. In particular, the course highlighted the importance of thoroughly assessing data quality before drawing biological conclusions and using exploratory analyses to identify patterns, sources of variation, or potential anomalies in the data. The course has increased my confidence in handling large datasets, performing reproducible analyses in R, and critically evaluating results. These skills will support both the analysis of my current research data and future collaborations involving advanced computational and systems immunology approaches.
